# Data provenance and access qualification

## What the manuscript analysis used

The manuscript describes analyses of processed, study-provided single-nucleus matrices, annotations, and a precomputed LSI–Harmony embedding associated with Liu et al. (2025). The analysis package does **not** include or redistribute the large cohort arrays.

Expected local input filenames are listed in `confirmatory_analysis/INPUTS_NOTE.txt`. Because those empirical inputs are not included in this archive, this package cannot independently prove which download route was used by the authors. The corresponding author must verify the exact source, access date, checksum, and applicable terms before final submission.

## Official resource distinction

The official Kellis Lab project portal lists processed outputs separately from raw data and metadata. It states that raw sequencing data and metadata originate from ROSMAP and require a Data Use Agreement through Rush University Medical Center or Sage Bionetworks/Synapse. Accordingly, the revised manuscript no longer states that all cohort materials are unrestricted.

Official project page: `https://compbio.mit.edu/AD_Multiomic_MultiRegion/`

## Required author verification before public release

Record the following in the permanent repository or data-access statement:

1. Exact processed files used, including filenames and cryptographic checksums.
2. Direct download source and date for each file.
3. Whether any metadata came from Synapse, Rush, or another controlled-access route.
4. The relevant DUA/approval identifier when controlled material was used.
5. Confirmation that raw sequencing files are not redistributed in the artifact.

Until that verification is completed, the manuscript uses qualified language: it identifies the processed inputs, distinguishes them from controlled raw data/metadata, and defers to the source resource's access terms.
